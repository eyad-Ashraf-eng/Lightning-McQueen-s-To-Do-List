The idea :
    This project is mini to-do list for Lightning McQueen it greets him, shows a menu of options to use them and it keeps showing after each action.

The features:
    the project provides some cool features:
    1 - adding tasks to a txt file.
    2- view the to-do list from the file.
    3- you can mark the tasks complete or not.
    4- you can delete tasks form them.
    5- it keeps showing the menu after every action until you quit.

requirements:
    you need a device that can show you the code , you need python 3.10 or higher (because of using match and case you can switch it with (if) statements to use it with lower versions)

challenges:
    1- marking the complete tasks
     solved by a loop that writes all the other tasks except the one completed then writes that task with adding completed at the end of the sentence
    2- making the menu show over and over again
        solved by using an infinity loop with a case of break.
